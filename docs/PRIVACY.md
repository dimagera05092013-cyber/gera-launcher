# Политика конфиденциальности GERA Launcher

Дата обновления: 18 ноября 2026.

GERA Launcher — локальное приложение. У проекта нет сервера, аккаунтов и
телеметрии. Всё, что GERA хранит, остаётся на вашем компьютере.

## Какие данные хранятся на компьютере

В папке данных (`%LOCALAPPDATA%\gera-launcher` на Windows,
`~/.local/share/gera-launcher` на Linux) лежат:

- настройки интерфейса и игры;
- профили (сборки): название, ник, путь к игровой папке, выбранный клиент;
- список серверов, который вы добавили вручную;
- скачанные клиенты, моды, ресурсы и Java;
- логи запуска, загрузки и сборки.

Эти данные никуда не отправляются. Их можно удалить вместе с папкой данных.

## Какие запросы уходят в интернет

GERA обращается только к тем адресам, которые нужны для выбранного действия:

- `api.github.com`, `github.com`, `codeload.github.com` — обновления GERA,
  клиенты Horizon, исходники для нативных модов, реестр модов;
- `piston-meta.mojang.com`, `piston-data.mojang.com`,
  `libraries.minecraft.net`, `resources.download.minecraft.net` — файлы
  Minecraft Java Edition;
- `api.adoptium.net` — Java (Temurin), если на компьютере нет подходящей;
- адреса серверов, которые вы добавляете: GERA отправляет обычный запрос
  списка игроков (Server List Ping), чтобы показать онлайн.

В этих запросах нет вашего имени, ника, идентификатора аккаунта или других
персональных данных. Передаётся только то, что нужно для скачивания файла или
проверки сервера.

## Аккаунты и авторизация

GERA не запрашивает вход Microsoft, не хранит пароли и токены и не создаёт
аккаунтов. Игра запускается с локальным ником.

## Дети

GERA не собирает данные о пользователях, поэтому отдельного режима для детей
нет.

## Изменения
