GERA Launcher 0.9.0 (beta)

Первый публичный релиз. Один и тот же код собирается для Windows и Linux.

Что уже работает:
• установка клиента Horizon из GitHub с проверкой SHA-256;
• запуск игры с нужной сборкой, ником, скином и игровой папкой;
• сборки: отдельные папки, дублирование, привязка модов;
• серверы: импорт из Horizon, иконки, баннеры, пинг и запуск в один клик;
• каталог модов Horizon и установка .hmod;
• свой сборщик нативных модов .hnmod;
• Material You: палитры, темы, лёгкий и тяжёлый режим.

Обновления:
Лаунчер сам проверяет GitHub Releases при запуске и показывает окно
«Доступна новая версия». Файл скачивается, проверяется по SHA-256 и заменяет
старый при перезапуске.

Скачать:
Windows 10/11 x64 — gera-launcher.exe (один файл, ничего рядом не нужно).
Linux x64 — gera-launcher-linux.

SmartScreen может предупредить: файл без платной цифровой подписи.
Нажмите «Подробнее» → «Выполнить всё равно».

Данные, сборки и серверы при обновлении не трогаются.
