# GERA Launcher 0.9.0 (beta)

Первый публичный релиз. Один и тот же код собирается для Windows и Linux.

## Что уже работает

- Установка клиента Horizon прямо из GitHub, с проверкой SHA-256.
- Запуск игры с нужной сборкой, ником, скином и игровой папкой.
- Сборки: отдельные игровые папки, дублирование, привязка модов.
- Серверы: импорт из Horizon, иконки, баннеры, пинг, онлайн и запуск в один клик.
- Каталог модов Horizon и установка `.hmod`.
- Свой сборщик нативных модов `.hnmod`.
- Material You: палитры, светлая/тёмная/системная тема, лёгкий и тяжёлый режим.

## Обновления

Начиная с этой версии лаунчер сам проверяет GitHub Releases при запуске.
Если есть новая версия — показывает окно «Доступна новая версия» с кнопками
«Обновиться» и «Позже». Файл скачивается, проверяется по SHA-256 и заменяет
старый exe при перезапуске. Скачивать вручную ничего не нужно.

## Скачать

| Система | Файл |
| --- | --- |
| Windows 10/11 x64 | `gera-launcher.exe` |
| Linux x64 | `gera-launcher-linux` |

Windows: один exe, ничего рядом не нужно. SmartScreen может предупредить —
«Подробнее» → «Выполнить всё равно»: файл без платной цифровой подписи.

Linux:

```sh
chmod +x gera-launcher-linux
mv gera-launcher-linux ~/.local/bin/gera-launcher
gera-launcher
```
