GERA Launcher 0.11.0

Надёжная загрузка ресурсов Minecraft и понятные ошибки:
• Загрузка переписана на собственный HTTP-клиент: работает без curl (которого
  нет на части Windows 10) и не ломается на путях с кириллицей и пробелами.
• Повторы с паузой, таймауты, разбор ответов 403/404/429/5xx, докачка после
  обрыва и перезапуска. Скачанное проверяется по SHA-1, повреждённое качается
  заново. Уже проверенные файлы повторно не скачиваются.
• Прогресс показывает этап, файлы, мегабайты и скорость; загрузку можно отменить.
• Кнопка «Проверить» у версии: полная проверка клиента, библиотек и ресурсов
  с конкретным списком недостающих файлов.
• Импорт принимает zip, папку версии, готовые ресурсы и папку .minecraft целиком.
  Неполные ресурсы не считаются готовыми, оригинал не удаляется.
• Ошибка запуска больше не «0 без причины»: game-launch.log хранит команду,
  код выхода, время работы и последние строки вывода; они же показываются
  в интерфейсе при раннем закрытии игры.
• Пять логов по этапам (launcher, assets-download, import, prepare,
  game-launch) и кнопки «Открыть папку логов», «Открыть последний лог»,
  «Скопировать отчёт».
• Подготовка Horizon: GERA сама подставляет официальный version JSON, который
  требует horizon-prepare, и официальный server jar из version JSON.

Обновление придёт само. Сборки, миры, моды и настройки не трогаются.
