GERA Launcher 0.10.0

Minecraft Java Edition прямо в лаунчере:
• Новый раздел «Java»: ник, список официальных версий Mojang и кнопка «Играть».
• GERA сама скачивает клиент, библиотеки, нативные файлы и все ресурсы (assets).
• Java берётся с вашего компьютера, если она подходит. Если нет — скачивается
  Temurin JRE нужной версии. Ресурсы, библиотеки и Java хранятся один раз.
• Запуск в один клик: «Играть» на главной странице раздела скачивает версию,
  если её ещё нет, и сразу открывает игру.
• Вход в аккаунт Microsoft не нужен: ник для одиночной игры и серверов
  в offline-режиме.
• Исправлен запуск Minecraft 26.3: нативные библиотеки LWJGL грузятся
  из jar-файлов и больше не падают с «Failed to locate library: liblwjgl.so».

Обновление придёт само: при следующем запуске GERA предложит версию 0.10.0.
Данные, сборки, серверы и моды не трогаются.
